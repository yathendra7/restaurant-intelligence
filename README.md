# 🍽️ Restaurant Intelligence

### Data Analytics & Interactive Restaurant Intelligence Dashboard

An interactive restaurant analytics platform developed as part of the **Cognifyz Data Analysis Internship**. The project transforms restaurant data into meaningful business insights covering cuisines, cities, pricing, ratings, customer engagement, geographic distribution, restaurant chains, and service availability.

🔗 **Live Dashboard:** https://restaurant-intelligence-krwls6vvvnpjfwarxzatml.streamlit.app/

🔗 **GitHub Repository:** https://github.com/yathendra7/restaurant-intelligence

---

## 📌 Project Overview

The restaurant industry generates large amounts of data related to customer preferences, ratings, pricing, cuisines, locations, and services.

This project analyzes restaurant data and presents the results through an interactive **Streamlit dashboard**, making complex data easier to understand and explore.

The dashboard is designed as a restaurant intelligence platform rather than a traditional static data analysis report.

## 🚀 Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/yathendra7/restaurant-intelligence.git
```

### 2. Open the project

```bash
cd restaurant-intelligence
```

### 3. Install dependencies

```bash
python -m pip install streamlit pandas numpy plotly
```

### 4. Run the dashboard

```bash
python -m streamlit run Dashboard/app.py
```

The dashboard will open in your browser.
